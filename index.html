❓ Ayuda y uso de datos

¿Cómo usar Konta?

  • 📦 Productos: agrega tus productos con precio, costo y stock. Marca "Es insumo" si es un ingrediente para recetas.
  • 🧾 Ventas: crea una factura con uno o varios productos, elige si pagaron en efectivo o transferencia y podrás imprimir el ticket.
  • 🏭 Producir: elige un producto con receta para ver los insumos necesarios y registrar la producción.
  • 📈 Análisis: revisa tus ingresos, categorías, ranking de productos y utilidad.
  • ⚙️ Config: exporta o importa Excel, activa alertas de stock bajo y administra tu cuenta.

🔒 Autorización de uso de datos

Konta guarda tus datos únicamente en este dispositivo (IndexedDB). La aplicación funciona sin internet y no envía tus datos a ningún servidor. Autorizo el uso de mis datos dentro de esta aplicación para el control de mi inventario y mis ventas.
